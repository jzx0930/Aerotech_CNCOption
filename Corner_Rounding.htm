Corner Rounding Overview

Note: This feature causes the controller to activate lookahead. For more information, refer to Program Block Lookahead Overview.

Corner rounding inserts an arc between two consecutive non-tangent LINEAR moves.

Figure: A Path With and Without Corner Rounding

Figure Label Description

The dashed line shows a path without corner rounding.

The solid line shows the same path with corner rounding.

The ROUNDING ON command turns on corner rounding. The ROUNDING OFF command turns off corner rounding. Use the ROUNDING AXES command to specify the two axes that are used for corner rounding.

Note: If you use the corner rounding and cutter compensation features at the same time, then you must use the same two axes for both features.

A corner rounding move is not inserted if any of the following conditions are true.

  • Either move of the two consecutive non-tangent moves is not a LINEAR move.
  • The angle between the LINEAR moves is 180°.
  • The insertion is limited by the MaxLookaheadMoves parameter.
  • One or more of the following commands are issued between the two moves: G53, G54, G55, G56, G57, G58, G59, POSOFFSET, G82, G92, FARCALL, and FARGOTO.

Corner rounding occurs only in moves that are between the ROUNDING ON command and the ROUNDING OFF command.

For Example

Corner rounding occurs in the code sample that follows.

  • An arc is not inserted between the LINEAR Y -10 and LINEAR X 10 Y 10 moves.
  • An arc is inserted between the LINEAR X 10 Y 10 and LINEAR X -10 Y 10 moves.
  • An arc is not inserted between the LINEAR X -10 Y 10 and LINEAR Y -10 moves.

Example

ROUNDING AXES X Y
ROUNDING TOLERANCE 1
LINEAR Y -10
ROUNDING ON
LINEAR X 10 Y 10
LINEAR X -10 Y 10
ROUNDING OFF
LINEAR Y -10

Note: In VELOCITY ON mode, acceleration can occur when the axis travels around arcs that are inserted by corner rounding. The acceleration can be high if the radius of the arc is very short. High accelerations can cause position errors, servo loop oscillation, and other motion problems. Use the CoordinatedCircularAccelLimit parameter to limit this acceleration.

Corner rounding uses position tolerance to find the radius of the inserted arc. The value that you specify for the ROUNDING TOLERANCE command is used as the position tolerance.
