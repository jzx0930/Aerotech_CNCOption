Deceleration Caused by Normalcy Mode

When a normalcy alignment move is necessary between two commanded non-tangential moves, the controller automatically puts a FORCEDDECEL command between the two moves so that the normalcy axis moves smoothly.

If two moves are meant to be tangential, but are non-tangential because of the limited precision of the LINEAR command values, the controller might put an unnecessary FORCEDDECEL command between the moves. For example, in the following figure, a normalcy alignment move is not necessary at Point D (between move C to D and move D to E). But, there might be a slight angular difference because of the precision of the values.

Figure: Normalcy Motion Illustration

Use the NORMALCY TOLERANCE command to prevent the controller from decelerating when it is not necessary. If an angle between two moves is less than the NORMALCY TOLERANCE value, then the controller will make the alignment move during the first MotionUpdateRate period of the second move and will not decelerate.

Note: If the <Tolerance> value of the NORMALCY TOLERANCE command is too high, the normalcy axis can move suddenly during the alignment.
