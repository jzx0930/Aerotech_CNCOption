Order of Transformation Application

If a combination of the following transformation are simultaneously active, they are applied to the programmed position in the following order:

Table:     Transformation Order

Transformation

Command

Corner Rounding

ROUNDING ON

Rotation

ROTATION Transformation

Software Home and Fixture Offsets

POSOFFSET, G54, G55, G56, G57, G58 and G59

Parts Rotation

G84

Mirroring

MIRROR ON

Polar

G46

Cylindrical

G47

Kinematics

Kinematic Transformation

Note: When mirror mode (MIRROR ON) is active, cutter radius compensation left becomes cutter compensation right, and conversely.
