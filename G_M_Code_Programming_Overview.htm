G-Code and M-Code Programming Overview

For the full syntax description of G-Code and M-Code syntax, refer to the RS-274D standard document.

A G-Code or M-Code is an identification letter that is immediately followed (no white space) by an integer value. G-Codes and M-Codes are not case sensitive. But, the parameters that are referenced from within a program are case sensitive.

Some G-Codes and M-Codes have AeroBasic equivalents. For more information on equivalents, refer to G-Code and M-Code Equivalents.

Note: You can use any AeroBasic command in CNC Operator Interface. Refer to AeroBasic Programming Overview for more information.

  

Some G-Codes and M-Codes define modes of operation that exist until changed by a different G-Code or M-Code. These are called Modal G-Codes and Modal M-Codes. All other G-Codes and M-Codes affect only the current program line. For task initialization of modal settings, refer to the Motion section of the Task parameters in the active parameter file.

You can issue immediate commands on a task while a program or another command is executing on that task. Commands that you can use as immediate commands are identified in the Immediate Command column of the G-Code List and M-Code List tables in this topic. You can issue immediate commands from the Execute Command box in Motion Composer or from the Execute Immediate Command box in CNC Operator Interface.

You can redefine G-Codes and M-Codes or you can add custom G-Codes and M-Codes to the CNC Option programming language. Refer to Custom Command Introduction for more information.

In a program, you cannot issue G-Codes or M-Codes on the same program line as an AeroBasic command. But, you can issue more than one G-Code and M-Code on the same program line. G-Codes and M-Codes do not have to be separated, or you can separate them with commas or white space. When you use more than one G-Code or M-Code on the same program line, obey the rules in G-Code and M-Code Execution.

All of the text that follows a comment character (" ; " or " // " or " ' ") is ignored.

Examples

' This is a comment.
G91         
// This is a comment.
G1 X10Y100 
; This is a comment.
N100 G1 X$global[0]
