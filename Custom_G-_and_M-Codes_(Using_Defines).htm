Custom G-Codes and M-Codes (Using Defines)

Use the #define preprocessor directive to replace a G-Code or M-Code with one or more of the AeroBasic commands.

There is no limit to the length of a program that is configured in a #define statement. The back slash (\) character, used as a continuation character, tells the #define statement to insert a line break and continue looking for text on the next line.

The last line of text of the #define statement includes the back slash (\) character, which shows that a blank line must follow. This lets multiple M-Codes be put on the same program line or on the same line with G-Codes.

For more information about defining M-Codes, refer to ONGOSUB, ON, and WAIT commands. WAIT lets you hold on a line until a certain condition is true or time out. The ON and ONGOSUB commands establish conditions that are monitored constantly during program execution, including when an I/O bit is on or off. This is useful for watching safety type conditions. The ON command sets a bit when the condition is true. The ONGOSUB and RETURN commands allow for more complex activities when the condition is satisfied, which includes full control over motion recovery if the condition occurs during motion.

In this example program, a blank line follows the ENDIF \ program line. This blank line is necessary if you want to put two or more codes on the same program line.

Example

#define M1100 \
$DO[1].X = 0 \
$global[0] = $DI[1].X \
IF( $BI[2] == 1 ) \
$BO[1] = 1 \
ENDIF \
                        
M1100
