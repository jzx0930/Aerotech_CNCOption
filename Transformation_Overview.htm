Transformation Overview

By using commands, you can specify coordinates in a standard coordinate system that are rotated or displaced by the controller into the coordinate system that is formed by the actual physical axes. Specifying these coordinates compensates for parts that are perfectly aligned to the physical coordinate system, which lets you run a single standard program on many parts that have a slightly different orientation.

For example, to correct for an offset on one or more axes, use the POSOFFSET SET command to define a nonzero point on one or more of the axes as zero. All absolute and incremental distances in the program are relative to those zero points.

Mirroring and part rotation can also be used with RAPID commands.

If you want asynchronous motion to include transformations, then you must select the Transform Jogs bit of the SystemCompatibility parameter in Configuration Manager.

For example

If parts rotation (G84) is active with an angle of 90° in an X-Y plane, a LINEAR X will always move the Y axis. However, asynchronous motion commands can move either X or Y, depending on the setting of the Transform Jogs bit of the SystemCompatibility parameter.

  • OFF (clear, default): an asynchronous move in X will move the X axis
  • ON (selected): an asynchronous move in X will move the Y axis

Note: All position values except program positions are "actual," meaning they reflect the positions as viewed in the coordinate system after all transformations. Program positions always reflect the values that you specify in the program and will differ from "actual" positions if transformations are present. For more information on positions, refer to Positions Overview.

When more than one transformation is active at the same time, the order in which the transformations are applied is not important. The following program examples are equivalent.

Example 1

' Activate preset displacement.
POSOFFSET SET X10

' Activate rotation.
G84 X Y F5

' Move.
LINEAR X10

Example 2

' Activate rotation.
G84 X Y F5

' Activate preset displacement.
POSOFFSET SET X10

' Move.
LINEAR X10
