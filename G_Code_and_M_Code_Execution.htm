G-Code and M-Code Execution

When you specify an F or E command on the same line as coordinated motion, the F or E command executes first. But, when a mode (for example, G91) is on the same line as an F or E command, the mode executes before the F or E command.

For Example

When you execute the following code in G71 mode, the X axis moves to 4 millimeters and gets 100 millimeters/minute at its fastest speed.

G90 G71 G75 G1 X4 F100

Codes are usually executed in the following order and are not affected by where they appear on the line. But, some codes are forced to appear in special positions on the line.

  1. Simple mode words (G90, G71, G75)
  2. F, E, S, or T commands (F4, T1)
  3. Spindle on or off (M3, M4, M5)
  4. Cutter compensation commands (G40, G41, G42, G43, G49)
  5. Motion mode commands (G0, G1, G2)
  6. Motion (X4 Y6)
  7. Control M-Codes (M0, M1, M2, M30, M47)

NOTE: Because they are executed in the order that they appear on the line, M-Codes that set I/O are an exception. In the following example, M1000 executes before G90, M1001 executes after G90, and M1002 executes after the move.

M1000 G90 M1001 G1 X4 M1002
