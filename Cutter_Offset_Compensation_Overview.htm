Cutter Offset Compensation Overview

The A3200 has two features that compensate for a cutting tool. You can use these features independently, or you can use both features at the same time.

  • Cutter Radius Compensation compensates for the radius of a cutting tool.
  • Cutter Offset Compensation compensates for the length and for the offsets of a cutting tool.

Note: This feature applies only to dominant axes. For information about axis types, refer to Axis Type Overview.

Cutter offset compensation compensates for the length and for the offsets of a tool. The offsets operate in the same plane (X,Y) as cutter radius compensation. The cutter length operates in an axis (Z) that is perpendicular to that plane.

Use the G44 command to specify the axes that you want to use with the tool offsets. If you want to specify an axis to use with tool length, specify a third axis in the G44 command.

The G143 command adds the tool offsets and the tool length to the appropriate move target coordinates. The G144 command subtracts the tool offsets and the tool length from the coordinates. The G149 command cancels all offset compensation. You can specify the tool offsets and lengths in the tool file, and then use the T Command to load the tool file.

When you enter (G143, G144 ) and exit (G149 ) cutter offset compensation, you usually supply a coordinated move on the same program line. For G143 and G144, that move is called the lead-on move. For G149, it is called the lead-off move. Lead-on moves gradually add the tool offsets during the move. When a lead-on move is completed, the cutter offsets are fully applied. When a lead-off move is completed, the cutter offsets are fully removed.

If you do not supply a lead-on move on the same line as the G143 or G144, the next coordinated move that is executed is the lead-on move. You can put commands that are not coordinated moves (except G41, G42, G40, G143, G144, and G149) between the G143 or G144 and the lead-on move. If the controller does not find a coordinated move to use as a lead-on or lead-off, then it does not apply cutter offset compensation.

If the lead-on move does not contain some motion on the axis that you want to use with cutter compensation, then cutter compensation does not occur.

Note: Only use cutter compensation for coordinated moves. While you are in cutter compensation mode, you can command non-coordinated motion on axes that are not a part of the cutter compensation plane. But, cutter compensation has no effect on the other types of motion.
