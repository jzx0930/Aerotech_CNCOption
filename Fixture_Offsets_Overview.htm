Fixture Offsets Overview

Use fixture offsets to program part dimensions in relation to a fixed point in space when you do not know the absolute coordinates of that point. Dimensional distances that you specify in the G90 programming units mode are related to this fixed point in space, not to the last software home position. Refer to G92 Command. Fixture offsets have no effect on moves in the G91 programming units mode.

The controller supports six fixture offsets. Use the applicable command (G54 through G59) with an axispoint argument to set and activate the offset.

In the example that follows, the AXISSTATUS item DATAITEM_ProgramPositionCommand shows the displacement from the active fixture offset (and the G92 setting, if necessary).

Example

' Software Home = {0,0}
' Point A = {4,2}

' Motion does not occur. Point A becomes {0,0}.				
G54 X4 Y2
' Movement to Point B {1,5} from Point A.				
G90 X-3 Y3
Figure: Illustration of Example

Note: If the fixture offsets are activated before part rotation (G84) starts, then the fixture offsets will be rotated.

Table:      Related Fixture Offset Commands

Command

G53 - Clear all fixture offsets

G54 - Fixture offset 1

G55 - Fixture offset 2

G56 - Fixture offset 3

G57 - Fixture offset 4

G58 - Fixture offset 5

G59 - Fixture offset 6

G153 - Suspend fixture offsets in this program block
