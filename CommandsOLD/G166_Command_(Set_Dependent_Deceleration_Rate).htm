G166 Command (Set Dependent Deceleration Rate)

Syntax: 
G166 P <DecelRate>

Example:

 
G166 P100    ; Set the deceleration rate for dependent axes
             ; to 100 primary units/s2.

Use the G166 command to set the value of the rate used for coordinated motion when decelerating on a dependent type axis. The G166 command is equivalent to setting the DefaultDependentCoordinatedRampRate task parameter for the current task. This command is always specified in primary units/s2.

In a move with dominant and dependent axes, the G166 command applies only if Inverse Dominance mode is active. Refer to G98 command for more information.

Refer to Axis Type Overview for details on axis dominance. If the axes are dominant, refer to G66 Command.
