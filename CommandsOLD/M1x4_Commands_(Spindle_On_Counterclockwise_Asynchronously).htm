M1x4 Commands (Spindle On Counterclockwise Asynchronously)

Syntax: 
M1x4
Example: 
M104    ; Spindle 0 on counterclockwise
 
M124    ; Spindle 1 on counterclockwise
 
M134    ; Spindle 2 on counterclockwise
 
M144    ; Spindle 3 on counterclockwise

These commands cause the spindle specified to start rotating counterclockwise (CCW). The speed of the spindle is determined by the S command and the operational mode with respect to the spindle speed G-Code group. There are four spindles available. If the spindle is rotating CCW, no action occurs. If the spindle is rotating CW, the spindle decelerates to zero and starts to accelerate CCW up to the S command. It does not wait for the spindle to accelerate up to full speed.

These M-Codes enable the drive if it is not already enabled. They set Bits 0 through 3 of the TaskStatus1 status item, respectively. These commands are asynchronous and start accelerating the spindle up to the commanded speed and immediately continue on with the next program block. Refer to M4 command, M24 command, M34 command, and M44 command for a synchronous version of the command.
