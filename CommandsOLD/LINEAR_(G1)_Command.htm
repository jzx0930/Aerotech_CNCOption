G1 Command (Linear Motion)

Syntax: 
G1 <AxisPoint> [F | E]

Example:

 
G1 X1.2 Y2.3 F100     ; Coordinated X Y move

The G1 command generates synchronized motion along a straight line for one or more axes. All specified axes start and stop motion at the same time. If G91 command distance mode is in effect, the motion will occur relative to the current axis positions. If G90 command distance mode is in effect, the motion is executed relative to the home or software home position.

The F command defines the combined vector speed, also called coordinated speed, that is used for the motion. If you are using MINUTES mode, then the combined vector speed is in user units per minute. If you are using SECONDS mode, then the combined vector speed is in user units per second. The F command is modal and you do not need to specify it on each program line. If you do not specify the F command, the controller uses the previously specified value of the F command for the motion. Refer to Feedrate Overview for more information.

When the G1 command is used in velocity profiling mode (G108 command), the motion of multiple commands are blended together without stopping between each move. A VELOCITY OFF command is used as the last command in a velocity profiled sequence of moves. This forces the axis motion to stop at the completion of the previous program line's target position.

You can use linear or sinusoidal ramping to configure the G1 command for rate-based, time-based, or distance-based ramping. Rate-based, time-based, and distance-based ramping can be configured by using the RAMP commands. In addition, you can use task parameters to set the acceleration and deceleration characteristics independently.

If the G1 command contains a mixture of dominant and dependent axes, the speed that is specified by the F command is used and only the dominant axes are included in the coordinated speed calculation. The dependent axes move at a rate that is required to maintain synchronism with the dominant axes. The G1 command uses the speed that is specified by the E command if only dependent axes are contained in the command. For more information about dominant and dependent axes, refer to Axis Type Overview. The E command is modal and you do not need to specify it on every program line. If you omit the E command, the controller uses the previously specified value for the motion.

The G1 command is modal and once issued the command can be omitted on subsequent program lines.

Advanced Topics
  • You can use a G1 motion command to infeed an axis, while camming, gearing, or handwheel motion is active.
  • You can specify a default feedrate for each task by using the DefaultCoordinatedSpeed task parameter.

Note: G108 mode does not blend PVT commands with G1, G2, or G3 commands. After the final PVT move in a sequence, the controller will always instantaneously return to zero velocity, even if G108 is active. To prevent axis jerking, set the final PVT move to return to zero velocity. G1, G2, and G3 commands decelerate to zero before proceeding to a PVT command, even if G108 is active.

Example

' Enable the axes.
ENABLE X Y 
' Home the axes.       
HOME X Y 
' Enable incremental programming mode.
G91
' Set the time base to seconds.
G76
' Move X and Y axes 10 units at 100 units/s.        
G1 X10 Y10 F100
' Move the X axis -10 units at 100 units/s.
G1 X-10
' Move the Y axis -10 units at 100 units/s.
G1 Y-10
' Enable absolute programming mode.
G90
' Move to absolute position x=50, y=20.
G1 X50 Y20
' Move to absolute position x=0, y=0.
G1 X0 Y0
' Enable incremental programming mode.
G91
' Enable velocity profiling mode.
G108
' Start a profiled sequence. The speed is 50 units/s.
G1 X10 Y10 F50
G1 X5 Y5
' Stop at the end of this move.
G1 X10 Y10
' Force a stop at the end of the previous line.
G109
' This move starts and stops at 0 speed.
G1 X-20 Y-20
