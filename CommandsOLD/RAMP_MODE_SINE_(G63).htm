G63 Command (Set Sinusoidal Acceleration)

Syntax: 
G63

Example:

 
G63    ; Enable sinusoidal mode.

The G63 command specifies sinusoidal acceleration and deceleration ramping for coordinated motion. This method is preferred over linear acceleration and deceleration (G64) because it results in less disturbance to the servo system. It does, however, require 1.57 times more peak current during acceleration than linear ramping for the same average acceleration.

The state of sinusoidal or linear programming mode is indicated by Bit 2 of the TaskMode status item or the G-Code status display.
