G26 Command (Coordinate System #2 Axis Assignment)

Syntax: 
G26 <axisMask>

Example:

 
G26 u v w     ; The u axis is on the X plane.
              ; The v axis is on the Y plane.
              ; The w axis is on the Z plane.

Use the G26 command to assign values to I, J, and K of the second coordinate system. I is assigned to the first axis in the mask, J to the second axis, and K to the third axis. The axes specified in the G26 command are used only with the G12 and G13 commands. Use the G27, G28, and G29 commands to select the plane within the second coordinate system in which the G12 or G13 circular motion is generated.

Note: The order of the axes in the axis mask is significant because it determines the mapping of the I, J, K. For example, G26 X Y Z is different than G26 Z Y X.
