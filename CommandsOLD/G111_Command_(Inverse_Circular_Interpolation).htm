G111 Command (Inverse Circular Interpolation)

Syntax: 
G111

Example:

 
G111    ; Invert the G2/G3 circular arc directions

The controller has the flexibility of inverting the direction of circular motion. When operating in the inverse circular interpolation mode, the arc directions are reversed.

By default, circular interpolation occurs as described in the description of the G2/G3and G12/G13commands, the plane select (G17/G18/G19 and G27/G28/G29) G-Code groups, and the I/J/K keywords. The active inverse/normal circular orientation mode is indicated by Bit 6 of the TaskMode status item.

Table:     G111 Command Mode

Commands Description

G2

Counterclockwise Circular Rotation Plane 1

G3

Clockwise Circular Rotation Plane 1

G12

Counterclockwise Circular Rotation Plane 2

G13

Clockwise Circular Rotation Plane 2

Use the G110 command to reset the circular directions.
