G96 Command (Specify Spindle Feedrate Units Mode)

Syntax: 
Gx96 <AxisMask>
Example:

 

 
G96 Y     ; Y axis is the radial axis used to calculate surface speed for Spindle 0.
 
G296 Y    ; Y axis is the radial axis used to calculate surface speed for Spindle 1.
 
G396 Y    ; Y axis is the radial axis used to calculate surface speed for Spindle 2.
 
G496 Y    ; Y axis is the radial axis used to calculate surface speed for Spindle 3.

Warning: In G96 mode use the MaxSpeedClamp axis parameter to limit spindle speed. You must limit the spindle speed because as the specified radial axis approaches the center of rotation of the spindle, the spindle can be commanded to excessive speeds which will cause axis faults.

The G96 mode determines the spindle rotation speed so that the speed on the surface of the spindle (tangential speed) is a specified constant speed. For example, if the radial axis is moved toward the center of the spindle to 5 millimeters (R) and the S command specifies a value of 2,000 millimeters per minute, then the resultant spindle rotation speed is 63.66 revolutions per minute.

The R value is the programmed position command of the radial axis, so it is measured after all transformations, including presets and fixture offsets, have been considered. For example, if the center of a lathe is at Y5 and you execute a G92 Y0 when at Y5, then according to the spindle, the center of the lathe (the point where the spindle speed goes infinite) is at Y5.

Use the MaxSpeedClamp axis parameter to limit the spindle speed. As the specified radial axis approaches the center of rotation of the spindle, the MaxSpeedClamp parameter value will prevent the spindle from being commanded to an infinite speed.

In G96 mode, the normal acceleration and deceleration axis parameters of the spindle will not be exceeded when changing the spindle speed. Therefore, the spindle rotation speed may lag behind the radial position if the radial position changes quickly or if the radius is small.

Additionally, in G96 mode the spindle rotation speed is recomputed every 10 time slices (nominally 10 milliseconds). Therefore, the spindle rotation speed always lags at least 10 milliseconds behind the radial axis position.

Note: Advanced users can use a Kinematic transformation (refer to Kinematic Transformation Overview) to implement spindle constant surface speed instead of using G96. Although Kinematic transformations are more complex than G96 mode, the rotational speed can be updated at a much faster rate because acceleration and deceleration parameter limiting are bypassed.

In either G97 or G96 mode, the S command always specifies the spindle speed. If you change G97 or G96 modes while the spindle is running, the value that is specified by the S command is reinterpreted by the new mode and the spindle accelerates or decelerates to the new speed.
