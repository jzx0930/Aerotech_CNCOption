G13 Command (CCW Circular Interpolation)

Syntax: 
G13 <EndingPoint> <CenterPoint>
Example: 
; The four following examples are alternate specifications of 
; the same circular arc, which 
; is shown in the figure 
; (examples assume G27, and starting point of {.5,3})
 
G91 G13 X2 Y-2 I-.5 J-2.5   	    ; G3, target+circle center
                                    ; specified (IJK method)
 
G91 G13 X2 Y-2 R2.5         	    ; G3, target+radius
                                    ; specified (R method)
 
G13 P78.69 Q11.31 R2.5              ; G3, angles+radius
                                    ; specified PQ and R method)
 
G13 Q11.31 I-.5 J-2.5               ; G3, angles+circle center
                                    ; (IJK and Q method)

The G13 command generates coordinated, synchronous motion that produces a counterclockwise circular arc by the coordinated motion of two axes in coordinate system 2.

Viewing the axes plane from the negative direction of a perpendicular axis (per the right hand rule), the arc direction is counterclockwise. Use G12 to generate clockwise motion on coordinate system 2. The axes specified in the command must be dominant type axes (as determined by the AxisType parameter). The F command determines the coordinated speed. When an F command is specified on the same line as a G2, G3, G12, or G13 command, the F command is executed first.

Using this command, you can generate two circular motions at the same time by programming a G12 or G13 on the same line as a G2 or G3. The F command specifies the feedrate for both circles.

Refer to G27, G28 and G29 commands for additional information on defining the axes planes.

Figure: G3 Circular Interpolation

Counterclockwise Circular Axes Plane

The G13 command can produce motion in any one of three planes, where each plane is defined by two of the three axes of the coordinate system. The three axes of coordinate system two are defined by the G26 command. The two axis plane that is used within coordinate system two is selected by the Plane Selection for Coordinate System 2 Commands .

Dual Circular Motion

You can have two circles execute simultaneously (on four different axes) by using the second coordinate system (G12 and G13) circular commands at the same time as the first coordinate system (G2 and G3) circular commands. (Refer to the Helixes and Dual Circular Motion section of the G2 and G3 commands for more information.)
