G98 Command (Set Inverse Dominance Mode)

Syntax: 
G98

Example:

 
G98 ; Enable inverse dominance mode for the active task.

Use the G98 command to enable inverse dominance mode. This mode reverses axis dominance. Dominant axes act as dependent axes, and dependent axes act as dominant axes. The dependent feedrate that is specified by the E command and the dependent acceleration and deceleration rates control the motion of coordinated moves with both dominant and dependent axes.

After you execute this command, inverse dominance mode is enabled until you execute a G99 (Clear Inverse Dominance Mode) command. Bit 4 of the TaskMode status value indicates whether inverse dominance mode is enabled.

Refer to Axis Type Overview for more information about axis dominance.

Example

' Enable inverse dominance mode.
G98
' For this example program, X is the dominant axis and Y is the dependent axis.
' Use the feedrate that is specified by the E command to calculate a move time of 0.2 minutes.
' This example program uses a dominant feedrate that is set to 50 units/min.		
G1 X10 Y72 F100 E10
