T Command

Syntax: 
T<toolNumber>

Example:

 
T10
T($global[0]+1)

This command loads a new tool. The specified tool must be contained in the Tool File. If the specified tool is not contained in the tool file, the following runtime task error occurs: Invalid tool specified. Only one tool can be active for all tasks.

You can add tools to the Tool File or edit tools already in the file with CNC Operator Interface. Refer to Configuring Tools for more information.

Loading a tool consists of taking the data stored in the tool file for that tool and loading it into the correct tool parameters. Loading a tool does not have an effect until the program moves on to the part by executing the G-Codes: G143, G144, G41, or G42. G41, and G42 will activate the Cutter Radius and Cutter Wear portion of the tool, while G143, and G144 will activate the Cutter Offsets and Length portions of the tool. The Cutter Wear is subtracted from the Cutter Radius to obtain the true tool radius.

Before you load the tool, you must define the compensated axes with the G44 command.

T commands can be executed on the same line as F, E, and S commands, and many other G-Codes. If the tool specifies a required speed, the F, E, or S command on that line or on a subsequent line overrides the specification, as defined by G-Code and M-Code Execution.

Tools must be numbered with nonzero positive integers. Specifying a tool word with a number of 0 selects the null tool, which has zero cutter radius, tool length, and tool offsets.

Note: You cannot specify a null tool to restore the feedrates that were previously specified by the F and S commands, and were active before the tool was loaded.

Warning: The Tool specification is not automatically removed after running the program. Make sure to put a T0 at the beginning and end of your program.
