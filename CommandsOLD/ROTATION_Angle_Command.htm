ROTATION Angle Command

Syntax:

 
ROTATION <RotationNumber> Angle <Axis> [<Multiplier>, <Offset>]
 
ROTATION <RotationNumber> Angle <Value>

Example:

 
ROTATION 1 Angle U 1.0, 100.0
 
ROTATION 1 Angle U
 
ROTATION 1 Angle 50.0

Use this command to set the rotation angle of the transformation. The input can be specified as either a constant numerical value or the ProgramPositionCommand value of the AXISSTATUS Status Function for a specified axis.

The arguments of this command are as follows.

  • ROTATION <RotationNumber> Angle <Axis> [<Multiplier>, <Offset>]

    • Argument Description

    <RotationNumber>

    Specifies the rotation instance to configure. Up to six rotations can be active per task, and the rotations are numbered one through six.

    <Axis>

    The name of the axis whose ProgramPositionCommand value will be used as the input.

    <Multiplier>

    An optional multiplier that can be used to scale the ProgramPositionCommand value of the input axis from user units to degrees. If no <Multiplier> is specified, then the argument defaults to 1 and the input axis is assumed to be programmed in degrees.

    <Offset>

    Must be specified in degrees. If no <Offset> is specified, then the argument defaults to 0.
  • ROTATION <RotationNumber> Angle <Value>

    • Argument Description

    <RotationNumber>

    Specifies the rotation instance to configure. Up to six rotations can be active per task, and the rotations are numbered one through six.

    <Value>

    A constant value to use as the input. Must be specified in degrees.
