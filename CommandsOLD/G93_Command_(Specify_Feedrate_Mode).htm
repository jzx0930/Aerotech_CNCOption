G93 Command (Specify Feedrate Mode)

Syntax: 
G93

Example:

 
G93            ; Set the feedrate to inverse time units.
G1 X100 F.5    ; Execute a 100 mm move in two seconds.

The G93 command defines a mode where F indicates the inverse of the time that is necessary to execute the commanded move distance. In this mode, the E command is ignored and the F command is always used for dominant and dependent axes.

NOTE: When you use G93 or G95 mode, the DependentSpeedScaleFactor Parameter does not scale the feedrate that you specify for the E Command.

Note: This mode does not have an effect on the feedrate of G0 moves.

Note: The active G93 mode, G94 mode, and Gx95 mode is shown by Bits 16 and 17 of the TaskMode status item.

Example

' Enable incremental programming mode.
G91
' Set the time base to seconds.
G76
' Set the user units to primary units.
PRIMARY
' The move will complete in two seconds.
G1 X100 F(1/2)
