G40 Command (Deactivate Cutter Radius Compensation)

Syntax: 
G40 <Lead-off Move>

Example:

 
' Deactivates cutter radius compensation.						
G40

Use the G40 command to deactivate cutter radius compensation. If cutter radius compensation is not active, the controller ignores this command.

When you deactivate cutter radius compensation, Aerotech recommends that you put a lead-off move on the same line as the G40. During the lead-off move, the controller gradually removes the offsets in order to deactivate cutter radius compensation. If you do not put a lead-off move on the same line as the G40, the controller uses the next coordinated move that it executes as the lead-off move. If the controller cannot find the next coordinated move, it does not remove compensation for the radius of the cutting tool.

At the end of the lead-off move, the controller decreases the values of the offsets to zero. To prevent damage to the cutting tool and the part, you must assemble lead-off moves carefully.

In the following figure, the distance between the target and the part (shows from Point B to the Part) must be greater than the radius of the cutting tool (shows as r). If the distance between the target and the part is less than the radius of the cutting tool, the lead-off move (shows from Point A to Point B) moves the cutting tool into the part.

Figure: Cutter Radius Compensation — Lead-off Move

Example

' Deactivate cutter radius compensation and gradually move the cutting tool away from the part.
G40 G1 X1.0 Y1.0 F100.0
