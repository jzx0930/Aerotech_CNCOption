ROTATION Transformation Overview

Note: ROTATION Transformation is similar in nature to Parts Rotation (G84), but they are not interchangeable.

ROTATION Transformation allows a program to specify axis positions in a programmed coordinate space, while the actual axis positions are transformed onto an actual coordinate space. The transformation consists of three linear Virtual Axes which are used for parts programming (InputAxis1, InputAxis2, and InputAxis3), and three linear physical axes that will have the resultant transform applied (OutputAxis1, OutputAxis2, and OutputAxis3). Additionally, a rotational axis can be used as an argument into the transformation. Up to six instances of this transformation can be active on a task at the same time. Each instance of the transformation completes the following operations.

  1. A displacement along Axis1, Axis2, and Axis3.
  2. A rotation in the Axis1-Axis2 coordinate system (about Axis3).

The transform is a space-fixed transform, in that each rotation is relative to the physical system. Thus, the output of ROTATION 1 is transformed by ROTATION 2, which is transformed by ROTATION 3, etc. The positions of the programmed input axes (InputAxis1, InputAxis2,and InputAxis3) remain unchanged by the transform. The positions of the output axes (OutputAxis1, OutputAxis2, and OutputAxis3) are based on the transform.

You can set the linear input axes (InputAxis1, InputAxis2, and InputAxis3) and the linear output axes (OutputAxis1, OutputAxis2, and OutputAxis3) by using the ROTATION InputAxes/OutputAxes command. Use the ROTATION Displacement command to apply an axis displacement before the rotation occurs. This allows for rotations about points other than the origin.

Use the ROTATION Angle command to set the rotation angle to either numerical values (constant) or axis positions (variable). If you use numerical values (constant) in the ROTATION Angle command, specify the angle in degrees. If you use axis positions, the axis you specify should be programmed in degrees.

The ROTATION Normalcy command can be used to indicate that the ROTATION Transformation should also transform a normalcy axis. Because normalcy operates in programmed space, you might need to use the ROTATION Normalcy command to generate a normalcy angle in post-transformed space. (Refer to Normalcy Motion Overview for more information about normalcy.)

After you set all of the axes and arguments, use the ROTATION On command to enable the ROTATION Transformation. Conversely, use the ROTATION Off command to disable the ROTATION Transformation. (Refer to ROTATION On/Off Command for more information.)

Example

The following program sets up a series of three rotations. Using the right-hand rule convention, the first rotation is about z, the second rotation is about x, and the third rotation is about y. The variables Өz, Өx, Өy, x1, y1, z1, x2, y2, z2, x3, y3, z3 represent values that you would input into the transformation. Axes x, y, z are the input axes that are used to program the part, and axes X, Y, Z are the output axes that will perform the machine motion.
