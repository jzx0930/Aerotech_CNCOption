G109 Command (Disable Velocity Profiling and Lookahead)

Syntax: 
G109

Example:

 
G109     ; Disable constant velocity mode (the
         ; blending of multiple moves together).

Use the G109 command to disable velocity profiling (G108) and cause the controller to decelerate to zero velocity between consecutive coordinated (G1, G2, G3) moves. G109 applies only to coordinated motion.

The state of this modal command is indicated by Bit 5 of the TaskMode status item.

If you are in velocity profiling mode and you issue a G109 command, the controller will decelerate to zero velocity after the last coordinated move before the G109 command.

You can issue a G109 command on the same line as a coordinated motion command. If you do this while in velocity profiling mode, the controller will decelerate to zero velocity before executing the move, and will decelerate to zero between subsequent coordinated moves.

Without velocity profiling mode, the controller always decelerates to zero velocity between consecutive coordinated moves. The example program and figure that follow show the behavior of the controller when velocity profiling mode is not active.

Example

' Enable forced deceleration mode.
G109
' Enable incremental programming mode.
G91
' Set the vector feedrate to 60.
F60.
' Move the X axis 1.0.
G1 X1.
' Move at a velocity of 120.
F120.
' Move the X axis 2.0.
G1 X2.
' Set the vector feedrate to 60.
F60.
' Move the X axis 1.0.
G1 X1.
' Dwell for one second.
G4 P1
' Move the X axis 1.0.
G1 X1.

Figure: Example of a Velocity Profile with G109

Note: Do not use the SLICE command while performing velocity profiling with a G108 - G109 block. Doing so will result in an error.
