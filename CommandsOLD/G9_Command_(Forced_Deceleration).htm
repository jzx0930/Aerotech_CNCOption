G9 Command (Forced Deceleration)

Syntax: 
G9 <MotionCommand>

Example:

 
G108           ; Enter constant velocity mode.
G1 X1 Y2       ; Blend motion on this line into the next line
G1 X3 Y4       ; as though it were one motion command
G9 G1 X5 Y6    ; and decelerate to zero velocity after this motion
               ; completes.

Use the G9 Command to force a move in a velocity profiled sequence (refer to G108 Command) to stop. The stop occurs in a controlled manner using the current ramp rate and occurs on completion of the motion command on the same line as the G9 Command.

This command is not modal.

Example

' Enable incremental programming mode. 
G91
' Enable velocity profiling mode.
G108
' Start the first move.
G1 X.5 F60
' This move stops when it completes.
G9 G1 X.5
' Start the second move.
G1 X1 F120
' This move stops when it completes.
G9 G1 X1
' Start the third move.
G1 X.5 F60
' This move stops when it completes.
G9 G1 X.5
' Dwell for one second.
G4 P1
' Move the X axis 1.0.
G1 X1.
' Disable velocity profiling mode.
G109

The figure that follows shows a velocity profile in G9 mode. The subsequent moves accelerate from zero velocity to the commanded feedrate. When executing a return move (from jog and return), the controller always decelerates to zero before resuming the move that was interrupted by the jog and return.
