G0 Command (Point-to-Point Motion)

Syntax: 
G0 <AxisPoint> [<AxisName>F<Speed>]
G0 <AxisPoint> [<AxisName>F<Speed>]

Example:

 
G0 X4.5 Y2 XF100 YF120    ; Specify independent axis speeds
                          ; and distances.

The G0 command generates single or multi-axis point-to-point motion. For a multi-axis move, all axes begin motion at the same time but do not end at the same time. Use the G0 command for operations where axes must be moved from one position to another as fast as possible without regard for coordination during the move or the path of the movement.

If G91 distance mode is in effect, the motion will occur relative to the current axis positions. If G90 distance mode is in effect, the motion will be executed relative to the home or software home position.

Each axis speed is specified independently by using the <AxisName>F<Speed> syntax with no intervening spaces. The axis speed is in units per second or units per minute, depending on the current time-base mode. Axis speeds are modal and need not be specified on every program line. If the speed is never specified, the G0 command uses the DefaultSpeed parameter.

The G0 command may be configured for rate-based, time-based, or distance-based ramping using either linear or sinusoidal ramping. These are configured using the RAMP <type><axis> commands. In addition, the acceleration and deceleration characteristics may be set independently using task parameters.

Advanced Topics

  • You can use a G0 command to infeed an axis while camming, gearing, or HANDWHEEL motion is active.
  • The G0 command internally clamps the commanded axis speeds to 100 percent MFO. Axis acceleration and deceleration rates are lower when the MFO is less than 100 percent. For more information, refer to MFO Overview.

Example

G90 
G76
' Move to X=10 at a speed of 20 units/s. Move to Y=5 at a speed 50 units/s.
G0 X10 Y5 XF20 YF50.
