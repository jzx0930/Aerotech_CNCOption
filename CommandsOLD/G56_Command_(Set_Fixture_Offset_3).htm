G56 Command (Set Fixture Offset 3)

Syntax: 
G56 <axisPoint>

Example:

 
G56 X8.9 Y$global[0] Z9; ; Set fixture offset 3 for X, Y, and Z axes.

G56 behaves just like G54, except it applies to Fixture Offset 3 instead of Fixture Offset 1

Example

' Enable fixture offset 3. All dimensional data is related to point (10,5,3). It is not related to point (0,0,0).
G56 X10. Y5. Z3.
