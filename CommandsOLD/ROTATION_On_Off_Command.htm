ROTATION On/Off Command

Syntax: 
ROTATION <RotationNumber> On
 
ROTATION <RotationNumber> Off

Example:

 
ROTATION 2 On
 
ROTATION 2 Off

Use the ROTATION ON command to enable an instance of ROTATION Transformation. At the point at which you enable the transformation, an offset is applied so that the programmed positions will transform onto the actual axis positions to avoid a sudden change in axis position. For the most predictable results, before you enable the transformation, set the ROTATION transformation so that the programmed position is equal to the actual position. This means that before you execute ROTATION On, set the input axes and output axes of the ROTATION InputAxes/OutputAxes command to the same location.

The ROTATION OFF command disables ROTATION Transformation. At the point at which you disable the transformation, the programmed positions are maintained so that neither the programmed axis positions, nor the actual axis positions will suddenly change. For the most predictable results, disable the ROTATION transformation in the same state that it was in when it was enabled.

If you disable transformations (ROTATION Off) at a position other than where they were enabled (ROTATION On), you can use the TRANSFORM POSITION RESET command to reset the programmed position of the transformation axes to the current machine position.

The <RotationNumber> argument specifies the rotation instance to enable or disable. Up to six rotations can be active per task, and the rotations are numbered one through six.
