MSO Command

Syntax:

 
MSO <spindle>, <value>
MSO <task>, <spindle>, <value>

Example:

 
MSO 0, 50      ; Changes MSO value of spindle 0 to 50 percent on the 
	       ; current task
MSO 2, 1, 150  ; Changes MSO value of spindle 1 to 150 percent on
	       ; task 2

Use the MSO command to set the manual spindle rotation speed override (MSO) for any spindle on a task. The MSO is a percentage varying from zero to infinity, where 100 percent represents normal or unaffected motion. The MSO percentage is multiplied by the programmed spindle speed to determine the actual spindle speed. For more information on programmed spindle speed, refer to S Command. This override affects only spindle (M3, M4, M5) motion. It cannot be changed if the MSOLock task mode is active (Bit 12 of TaskMode).

If the Spindle0MSOInput, Spindle1MSOInput, Spindle2MSOInput or Spindle3MSOInput parameter is not set to -1, the controller overwrites the MSO value with the value obtained from the specified analog input. The MSO value only reflects the requested spindle rotation speed override. The MaxSpeedClamp parameter may limit the actual rotation speed.

The acceleration and deceleration during MSO changes is the same as the acceleration and deceleration followed at the beginning and end of the move, which is determined by the type of motion. Refer to the Types of Motion section of the Acceleration and Deceleration Ramping Overview for more information.

In addition to delays due to the sample rate, the operation of an MSO change during a coordinated move is delayed by a time interval in milliseconds, determined by the MotionUpdateRate parameter.
