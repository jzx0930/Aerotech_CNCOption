S Command

Syntax:

 
S[<Spindle>]<Speed>

Example:

 
S[2]100			; Set the speed for Spindle 1 to 100
S200			 ; Set the speed for Spindle 0 to 200

Use the S command to define the speed of the specified spindle. The task interprets the speed in the user units of the task when executing spindle motion.

Table:     S Command Arguments

Argument

Description
<Spindle>

Number of the spindle to set the speed on. This value is one-based, so a <Spindle> value of 1 corresponds to Spindle 0. If you do not specify a spindle number, the controller sets the speed on Spindle 0.
<Speed>

New speed

S commands apply only to spindle motion (motion initiated by M3 or M4 commands). You can configure an axis as a spindle by selecting it in the Spindle0Axis, Spindle1Axis, Spindle2Axis, or Spindle3Axis task parameters. The actual spindle speed can vary from the programmed rate if the MSO value is not 100 percent.

If you issue a new S command when the spindle is running, the speed immediately begins accelerating or decelerating to the new value that is specified by the S command. But, the program does not wait for that acceleration or deceleration to complete. The program will immediately continue executing with the next line of the program.
