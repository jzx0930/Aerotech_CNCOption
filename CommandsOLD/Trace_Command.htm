TRACE END Command

Defines the start of the retrace history.

Syntax: 
TRACE END

Example:

 
TRACE END

Use the TRACE END command to define the earliest program line in the retrace history. This prevents the controller from executing past the TRACE END line when the task is in Retrace mode.

The controller keeps a history of moves and synchronized commands that can be used for retrace. The number of moves and synchronized commands in the retrace history is determined by the value set for the MaxRetraceMoves Parameter.

Some AeroBasic commands such as asynchronous motion, string assignments, file operations, HOME, and other commands cannot be retraced through. If you execute one of these commands during normal program execution, the controller will clear the retrace history. If the controller reaches the end of the retrace history during retrace, the task will error.

To prevent a task from reaching the end of the retrace history and causing an error, use the TRACE END command. When retrace is active, the controller will not retrace past the TRACE END command. The controller will stay on the TRACE END command until retrace is disabled. The TRACE END command is ignored when retrace is not active.

For Example

In the program that follows, the TRACE END command prevents the controller from executing commands after the TRACE END line. If the TRACE END were not present, the controller would give an error after "LINEAR X0 Y10" in retrace because there would not be retrace history for the controller to execute. 

ENABLE X Y
HOME X Y

' The program does not execute past this command during retrace.
TRACE END

LINEAR X0 Y10
LINEAR X10 Y0
LINEAR X0 Y5
LINEAR X5 Y0
LINEAR X0 Y-5
LINEAR X10 Y0
LINEAR X0 Y-10

END PROGRAM

In Retrace mode, if the program gets to a TRACE END, it will wait on the TRACE END line until you deactivate Retrace mode. When you deactivate Retrace mode while the program waits on the TRACE END line, the next move that the controller executes is the motion command that is immediately after the TRACE END line.

If you activated retrace with the Retrace mode section of the CNC Operator Interface or with the RETRACE command, the program will feedhold on the TRACE END line. If you activated retrace with negative MFO, motion after the TRACE END line will start immediately. (For more information about the different methods of retrace, refer to Retrace Overview.)

TRACE END does not change the direction of program execution. To switch the direction of program execution you must deactivate Retrace mode.
