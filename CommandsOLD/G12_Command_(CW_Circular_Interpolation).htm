G12 Command (CW Circular Interpolation)

Syntax: 
G12 <EndingPoint><CenterPoint>

Example:

 
; The following four examples are alternate specifications 
; of the same circular arc, which is shown in the figure below
; (examples assume G27, and starting point of {.5,3})
 
G91 G12 X2 Y-2 I.5 J-1.5   	   ; CW: target+circle center
                                   ; specified (IJK method)
 
G91 G12 X2 Y-2 R1.58114   	   ; CW: target+radius specified
                                   ; (R method)
 
G12 P101.31 Q-11.31 R1.58114       ; CW: angles+radius
                                   ; specified (PQ and R method)
 
G12 Q-11.31 I.5 J-1.5              ; CW: angles+circle
                                   ; center (IJK and Q method)

The G12 command generates coordinated, synchronous motion that produces a clockwise (CW) circular arc by the coordinated motion of two axes in coordinate system 2.

Viewing the axes plane from the negative direction of a perpendicular axis (per the right hand rule), the arc direction is clockwise. Use G13 to generate counterclockwise motion on coordinate system 2. The axes specified in the command must be dominant type axes (as determined by the AxisType parameter). The F command determines the coordinated speed. When an F command is specified on the same line as a G2, G3, G12 or G13 command, the F command is executed first.

Using this command, you can generate two circular motions at the same time by programming a G12 or G13 on the same line as a G2 or G3. The F command specifies the feedrate for both circles.

Figure: CW Circular Interpolation

Refer to G27, G28, and G29 commands for more information on defining the axes planes.

Clockwise Circular Axes Plane

The G12 command can produce motion in any one of three planes, where each plane is defined by two of the three axes of the coordinate system. The three axes of coordinate system two are defined by the G26 command. The two axis plane that is used within coordinate system two is selected by the G27, G28, and G29 commands.

Dual Circular Motion

You can have two circles execute simultaneously (on four different axes) by using the second coordinate system (G12 and G13) circular commands at the same time as the first coordinate system (G2 and G3) circular commands. Refer to the Helixes and Dual Circular Motion section of the G2 and G3 commands for more information.
