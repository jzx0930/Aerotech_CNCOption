G91 Command (Enable Incremental Programming Mode)

Syntax: 
G91

Example:

 
G91    ; Specify the distance as incremental.

The controller interprets move target positions as absolute or incremental. In incremental mode, move target positions are relative to the current axis location. You can set incremental programming mode at any time during program execution. This command is modal and stays in effect until absolute programming mode is specified.

You can use the DefaultProgrammingMode parameter to set the default mode that is used by the task.

The incremental programming mode state is shown by Bit 1 of the TaskMode status value of the TASKSTATUS Status Function.

The RolloverCounts axis parameter does not have an effect on the direction of travel of incremental moves.

The example program that follows executes as if the axes start at position (0, 0).

Example

' Enable incremental programming mode.
G91
' Set the feedrate for subsequent moves.
F100.
' Move the X and Y axes an increment of 10.0.
G1 X10.0 Y10.0
' Move the X axis 15.0 and the Y axis 25.0 from the axis position.
G1 X15 Y25
' Move the X axis 15.0 and the Y axis 10.0 from the axis position.
G1 X15. Y10.
