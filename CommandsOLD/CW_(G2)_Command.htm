G2 Command (Clockwise Motion)

Syntax:

 
G2 <EndPoint> <CenterPoint> [F]

Example:

 
; The examples below are alternate specifications of the same
; circular arc that shows in Figure: G2 Circular Interpolation. Examples assume
; Coordinate System 1 (G17), G91 incremental distance mode, and a starting point
; of {.5,3}.
 
G2 X2 Y-2 R1.58114               ; End point and radius specified
                                 ; (R Method).
 
G2 X2 Y-2 I.5 J-1.5              ; End point and circle center
                                 ; specified (IJK method).
 
G2 P108.435 Q-18.435 R1.58114    ; Angles and radius specified
                                 ; (P and Q Method and R Method).
 
G2 Q-18.435 I.5 J-1.5            ; Ending angle and circle center
                                 ; (Q Method and IJK Method).
Figure: G2 Circular Interpolation

NOTE: This command applies only to dominant axes. Use the AxisType parameter to specify a dominant or dependent axis.

The G2 command generates a clockwise circular arc. To create the arc, you must use this command to specify the end point and the center of the arc. Use this command to explicitly specify the end point of the arc or use the P and Q words to specify the absolute starting angle and the absolute ending angle of the arc. If you use the G91 incremental distance mode, the end point that you specify is related to the current axis positions. If you use the G90 absolute distance mode, the end point that you specify is related to the home or software home position.

To specify the center of the arc, use the IJK Method or the R Method.

For information about how to prevent positional errors that can occur in G2 and G3 motion, refer to Imprecision of Generated Circular Motion.

Note: G108 mode does not blend PVT commands with G1, G2, or G3 commands. After the final PVT move in a sequence, the controller will always instantaneously return to zero velocity, even if G108 is active. To prevent axis jerking, set the final PVT move to return to zero velocity. G1, G2, and G3 commands decelerate to zero before proceeding to a PVT command, even if G108 is active.

Note: When in VELOCITY ON mode and using CW, CCW, G2, or G3 arcs with small radii, use the CoordinatedCircularAccelLimit parameter to limit one of the two axis accelerations caused by traveling the arc. High axis accelerations can cause position errors, servo loop oscillation, and other motion problems.

Methods of Determining the Circular Center Point

Use one of these methods to specify the center of an arc. To specify the center of an arc as an offset from the starting position of a circle, use the IJK Method. To specify the center of an arc as a radius, use the R Method.

IJK Method

Use this method to specify the center of an arc as an incremental offset from the starting position of a circle. The radius of the generated arc is the distance between the starting position and the specified offset. You can use the G118 command to specify the circle center coordinates I, J, and K in absolute mode. Use the G16 command to specify the I, J, and K axes.

If you use the R Method to specify the center of the arc as a radius, you cannot generate a full 360° circle.

Creating a Full Circle with the IJK Method

To create a full 360° circle with the IJK Method, specify an end point that is the same location as the starting point of the G2 motion.

This example executes as if you are using the G91 incremental distance mode and you previously issued a G16 X Y command so that the I axis is X and the J axis is Y.

Example

' Specify an offset of one unit in the positive direction on
' the X axis, creating a center at (1,0).
' The motion starts at (0,0), moves clockwise around
' (1,0) with a radius of one unit, and stops when the motion 
' makes a full circle that completes at (0,0).
				 
G2 X0 Y0 I1 J0
R Method

NOTE: You cannot use the R Method to create a full 360° circle. To create a full circle, use the IJK Method.

Aerotech recommends that you do not use the R Method to program arcs that are almost full circles or almost half circles. In these arcs, a small error in the location of the end point causes a much larger error in the center point of the arc. As an alternative, Aerotech recommends that you either divide the arc into two or more smaller arcs or use the IJK Method to construct the arc.

If you use the R Method, make sure that you specify the correct arc that you want to use.

  • If the radius is positive, the controller generates a shorter arc that is always 180° or less.
  • If the radius is negative, the controller generates a longer arc that is always between 180° and 360°.
Figure: R Method Arcs

Methods of Determining the Circular End Point

Use one of these methods to specify the end point of an arc.

Explicitly Declaring an End Point

You can use this command to explicitly declare a circular end point.

If you use the G91 incremental distance mode, the end point that you specify is related to the current axis positions. If you use the G90 absolute distance mode, the end point that you specify is related to the home or software home position.

P and Q Method

NOTE: You must use the R Method with the P and Q Method. When you use the P and Q Method, the arithmetic sign of the R word does not have an effect and you cannot explicitly specify the end point of an arc.

Use the P and Q words to specify, in degrees, the absolute starting angle (P word) and ending angle (Q word) of an arc. Each of these absolute angles is measured counterclockwise from a line that is drawn through the circular center point of the arc. This line is parallel to the X axis. If the starting and ending angles of the arc are the same, the controller generates a full 360° circle.

Q Method

NOTE: You must use the IJK Method with the Q Method. When you use the Q Method, you cannot explicitly specify the end point of an arc or use the R Method.

Use the Q word to specify the absolute ending angle of an arc. The angle is measured counterclockwise from a line that is drawn through the circular center point of the arc. This line is parallel to the X axis.

F Command

The F command defines the combined vector speed, also called coordinated speed, that is used for the motion. If you are using MINUTES mode, then the combined vector speed is in user units per minute. If you are using SECONDS mode, then the combined vector speed is in user units per second. The F command is modal and you do not need to specify it on each program line. If you do not specify the F command, the controller uses the previously specified value of the F command for the motion. Refer to Feedrate Overview for more information.

Clockwise Circular Axes Plane

By default, the G2 command generates circular motion in the X and Y axis plane. This command can also generate motion in the axis planes of the first coordinate system, where each plane is defined by two of the three axes in the coordinate system. Refer to Figure: Coordinate System One. G16 command specifies the three axes of the first coordinate system. G17, G18, and G19 commands specify the two-axis planes that you use in the first coordinate system.

Figure: Coordinate System One

Helixes and Dual Circular Motion

To make helical interpolation, configure two axes to generate circular interpolation and a third axis to generate linear interpolation. Specify a G2 or G3, G12 or G13, and a G1 command on the same program line.

You can use the G12 and G13 circular commands of the second coordinate system with the G2 and G3 circular commands of the first coordinate system to specify two circles to execute at the same time on four different axes. The feedrate that you specify for the F command determines the velocity for the circular motion in both coordinate systems.

Example

To generate a helix or dual circular motion, you must put the G-Codes and their command arguments on the same program line. The arguments to the G1 command must follow the G1 command, the arguments to the G2 command must follow the G2 command, and the arguments to the G12 command must follow the G12 command.

' Configure coordinate systems.
G16 X Y Z
G26 xx yy zz
						
' Helical motion.
G1 Z5.0 G2 X1.0 Y1.0 I1.0 J0.0 F100
						
' Dual circular motion on the X, Y and xx, yy axes.
G2 X1.0 Y1.0 I1.0 J0.0 G12 xx1.0 yy1.0 I1.0 J0.0 F100
