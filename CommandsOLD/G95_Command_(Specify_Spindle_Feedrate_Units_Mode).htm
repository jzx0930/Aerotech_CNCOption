G95 Command

Syntax: 
Gx95
Example: 
G95     ; Feedrate in [distance units/Spindle 0 revolutions].
 
G295    ; Feedrate in [distance units/Spindle 1 revolutions].
 
G395    ; Feedrate in [distance units/Spindle 2 revolutions].
 
G495    ; Feedrate in [distance units/Spindle 3 revolutions].

The G95 command causes feedrates that are specified by the F or E commands to be interpreted in units per spindle revolution. This causes the axes to move at a speed proportional to the absolute value of the programmed spindle speed (S command). Variations in the spindle's actual speed are not tracked and do not have an effect on the speed of the coordinated motion.

In this mode, units that are specified by the F and E commands apply.

Bit #17 of the TaskMode status item indicates if Gx95 mode is currently active.

NOTE: When you use G93 or G95 mode, the DependentSpeedScaleFactor Parameter does not scale the feedrate that you specify for the E Command.

Note: This mode does not have an effect on the feedrate of G0 moves.

Example

' Feedrates are linked to Spindle 0.
G95
' Set the user units to primary units.
PRIMARY
' Move the X axis 50 mm for each revolution of Spindle 0.
G1 X100 F50
