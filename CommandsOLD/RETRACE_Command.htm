RETRACE Command

Enables or disables Retrace Mode for a task.

Syntax:

 
RETRACE ON
RETRACE <Task> ON
RETRACE OFF
RETRACE <Task> OFF

Example:

 
RETRACE 1 ON     ' Enable Retrace Mode on task 1
RETRACE 1 OFF    ' Disable Retrace Mode on task 1

Use the RETRACE command to enable or disable Retrace Mode on the specified task. If you do not specify a task, the command will enable or disable Retrace Mode on the current task.

The controller keeps a history of moves and synchronized commands that can be used for retrace. The number of moves and synchronized commands in the retrace history is determined by the value set for the MaxRetraceMoves Parameter.

Some AeroBasic commands such as asynchronous motion, string assignments, file operations, HOME, and other commands cannot be retraced through. If you execute one of these commands during normal program execution, the controller will clear the retrace history. If the controller reaches the end of the retrace history during retrace, the task will error.

To prevent a task from reaching the end of the retrace history and causing an error, use the TRACE END command. When retrace is active, the controller will not retrace past the TRACE END command. The controller will stay on the TRACE END command until retrace is disabled. The TRACE END command is ignored when retrace is not active.

For more information about retrace, refer to Retrace Overview.
