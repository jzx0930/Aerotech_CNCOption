G47 Command (Enable Cylindrical Coordinate Transformation)

Syntax: 
G47 <RotaryAxis> F <radius>

Example:

 
G47 C F.05     ; Enable cylindrical coordinate transformation
               ; rotary axis is the C axis, the radius of the
               ; part is .05 units

The G47 command enables a transformation from the X/Y Cartesian plane into a cylindrical (C, Y) coordinate system. G47 command requires the use of the G52 command to define the axes.

The cylindrical coordinate system has a rotational axis that holds the part to be machined, (the C axis in the following figure) and a linear axis (the X axis in the following figure) that moves parallel to the center of rotation of the rotational axis.

After you enable the G47 command, the controller automatically translates G1 commands, G2 commands, and G3 commands for use in the cylindrical coordinate system as if a Cartesian coordinate system (X, Y) is present. These commands act on the axial axis (X axis in the following figure) and a virtual axis that moves along the surface of the cylinder (Y axis in the following figure).

Note: An additional axis that is perpendicular to the center line of rotation of the rotational axis can be present if you want to position a tool or the part to be machined. However, this axis is not dependent on, and not controlled by, the coordinate transformation.
Figure: X, Y Rotational and Optional Additional Axes

The G45 command disables the cylindrical transformation. You must always issue the G45 command before you enable the G47 command mode.

You cannot use polar coordinate transformations (G46 command) in the G47 command mode. You cannot generate asynchronous motion or jog the axes while this mode is active.

Verify the state of the cylindrical transformation mode. You can do this by using the TASKSTATUS Status Function to view the RthetaCylindricalActive bit 2 of TaskStatus2, or by looking for the G47 command in the Modal Status tab of CNC Operator Interface.

Warning: Only G1 commands, G2 commands, G3 commands, and cutter compensation generated motion are valid under this mode of operation. Do not use G0 commands or any other type of axis motion when the cylindrical coordinate transformation is active.

The example programs that follow show the commands that are required to enable and disable cylindrical coordinate transformation. The axis designations are consistent with Figure: X,Y Rotational and Optional Infeed Axes.

Example

ENABLE X Y C
HOME X Y C
' Disable cylindrical coordinates before enabling.
G45
' Specify X as the axial axis and Y as the circumferential axis.
G52 X Y

' Enable cylindrical coordinates. The cylinder radius = 3.0.
G47 C F3.0

' Generate axis motion on the surface of the cylinder. Axis X runs along the axis of the cylinder.
' Axis Y runs around the circumference of the cylinder.
' This move makes the C axis go to 38.197 degrees.
G9 G1 X2.0 Y2.0
' ...              
' G1, G2, and G3 motion commands.
' ...
' ...
' Disable cylindrical coordinates.
G45
M2

Example

'
' This example cuts 90 degrees of thread. It ascends clockwise on the X axis looking up the X axis, on a 3 inch radius cylinder. It has a pitch of 0.1 inch.
' 
ENABLE X Y C
HOME X Y C
' Disable G47 mode before enabling it.
G45
' The cylinder radius = R = 3.0 inch.
G52 X Y
G47 C F3
G91
' 4.712389 inch = 2PI*R*90° / 360°.
G1 Y4.712389 X0.1
' Disable G47 mode.
G45
