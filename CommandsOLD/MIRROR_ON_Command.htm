MIRROR ON Command

Syntax: 
MIRROR ON <axisMask>

Example:

 
MIRROR ON X V Z    ; Activate mirroring of the X, V, and Z axes.

The MIRROR ON command activates the mirror image function for the axes specified in the command. Mirroring is disabled on any axis not specified in this mask when the command is executed. Mirroring is not cumulative.

Verify the state of the mirroring mode by viewing the MirrorActive bit of the TaskStatus2 status item.

The MIRROR ON command operates in both the relative and absolute mode (ABSOLUTE/INCREMENTAL). In relative mode, the origin, or point in the plane at the moment mirroring takes place, is the active position in the plane. In absolute mode, the origin is the home position.

While in the absolute mode, you must be at the software home defined by the POSOFFSET command when activating the mirror mode, or unexpected results occur.

Use the MIRROR OFF command to deactivate the mirror image function.

Note: When mirror mode is active, cutter radius compensation left becomes cutter radius compensation right, and conversely.

Example: Mirror Image Example Program

' Enable incremental programming mode.
INCREMENTAL
' Move the X and Y axes to coordinate (0, 0) which is the home position.
HOME X Y
' Disable the mirror image function.
MIRROR OFF
' Call subroutine BOX1, which draws a box in the first quadrant of Figure: Mirror Image Example.
CALL BOX1
' Enable the mirror image function for the X and Y axes, which changes the positive X and Y values to negative values.
MIRROR ON X Y
' Call subroutine BOX1, which draws a box in the third quadrant of Figure: Mirror Image Example.
CALL BOX1
' Disable the mirror image function.
MIRROR OFF
' Stop the program.
END PROGRAM

' Define subroutine BOX1.
DFS BOX1
    ' Set the feedrate to 100.
    F100.
    ' Start a positive linear move for the X and Y axes.
    LINEAR X2. Y4.
    ' Start a positive linear move for the X axis.
    X2.
    ' Start a positive linear move for the Y axis.
    Y2.
    ' Start a negative linear move for the X axis.
    X-2.
    ' Start a negative linear move for the Y axis.
    Y-2.
    ' Start a linear move of the X and Y axes to the starting position.
    X-2. Y-4. 
' End of the subroutine.
ENDDFS
