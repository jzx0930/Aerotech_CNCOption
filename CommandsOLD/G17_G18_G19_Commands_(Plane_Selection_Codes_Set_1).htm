G17, G18, G19 Commands (Plane Selection Codes Set 1)

Syntax: 
G17 or G18 or G19

Example:

 
G17

G17, G18, and G19 are used only in the context of G2 or G3 commands.

G17 selects Plane 1; G18, Plane 2; and G19, Plane 3 (refer to the following figure). The G17 command is the default. The active plane is indicated by Bits 23 through 25 of the TaskStatus2 status item.

Figure: Coordinate System 1 (Clockwise or G2 motion)

Example

INCREMENTAL
' I=X, J=Y, K=Z. This is the default.
G16 X Y Z
' Plane={I,J}. This is the default.
G17
' The arc is in the XY plane.
G2 X1 Y1 I1 J0
' Change to I=U, J=A, K=B.
G16 U A B
' The arc is in the UA plane.	
G2 U1 A1 I1 J0
' Change the U and A axes so that I=A, J=U, K=B.
G16 A U B
' The arc is in the UA plane, but I=A and J=U.
G2 U1 A1 I0 J1
' Change back to the default so I=X, J=Y, K=Z.
G16 X Y Z
' But change the plane to {J,K}.
G19
' Corrected. Now {J,K} must be used because there was no change in the G16 setting. Thus {J,K} continues to match the X,Y axes.
G2 Y1 Z1 J1 K0
