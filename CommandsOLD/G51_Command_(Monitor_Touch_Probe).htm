G51 Command (Monitor Touch Probe)

Syntax: 
G51 [<axisMask>]

Example:

 
G51 X Y    ; Monitor X and Y axes
 
G51        ; Disable probe monitoring

After the PROBE command configures the touch probe, the G51 command enables monitoring of the probe input. The G51 command can be used after previous G51 commands to repeat the cycle without issuing additional PROBE commands. A G51 command without an <axisMask> argument disables probe monitoring.

When you issue the G51 command, the ProbeCycle bit of the Task Status 0 status item is set. This bit will remain active until the probe input is activated or the probe command is disabled by aborting the task or issuing a G51 with no <axisMask>.

The axis positions of the specified axes are stored in the variable array in the order of the standard axis names, not in the order of the axis names specified in the G51 command. The variable array is specified with the PROBE MODE command.

Note: If the motion of one axis of a multi-axis motion command (for example, G1) is interrupted by the probe input, all motion for that command will be stopped.
