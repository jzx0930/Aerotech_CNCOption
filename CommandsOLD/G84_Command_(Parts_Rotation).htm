G84 Command (Parts Rotation)

Syntax: 
G84 <axisMask> [F<Expression>]
The <axisMask> must contain exactly two axis letters.

Example:

 
G84 X Y F$Var1    ; Set part rotation angle for the X-Y plane
                  ; from the value in the $Var1 variable.
G84 X Y           ; Turn off parts rotation.

The G84 command defines both the plane and angle of parts rotation. The parts rotation programming feature permits changing the orientation (in a plane) of a sequence of moves without changing the move coordinates or changing permanent coordinate reference frames.

The angle must be specified in positive degrees (0 – 359), relative to the axes' plane, as shown in the following figure. If no angle is specified, parts rotation is disabled for the specified axes.

The angle is relative and based on the last angle specified in a G84 command, as shown in the following figure.

Figure: The Effect of the G84 (Parts Rotation)

To implement parts rotation with an absolute angle value, always disable parts rotation and reactivate it. Refer to the example program that follows.

Example

DVAR $Angle
' Disable parts rotation.
G84 X Y
' $Angle is now in absolute degrees.
G84 X Y F$Angle

The center of rotation is the coordinate from which it is activated. If the fixture offsets are activated before part rotation (G84) starts, then the fixture offsets will be rotated. You can activate parts rotation at nonzero coordinates, which causes coordinate rotation around an offset point. However, when rotating about an offset point when you disable parts rotation, you must be physically at the same point in space at which parts rotation was activated. Refer to Order of Transformation Application for more information on rotation when multiple transformations are present.

This command block must occupy its own line (no other blocks on the line).

G84 is a modal command and part rotation is active until deactivated. Parts rotation is not disabled by disabling the axis or by the HOME command. You can only disable parts rotation with a controller reset or a G84 command that does not have an F command.

You can verify the state of the parts rotation mode by viewing the RotationActive bit of _TaskStatus2 using the TASKSTATUS Status Function_TaskStatus2, or by looking for G47 in the Modal Status tab in the Operator Interface. The active state of this command is indicated by Bit 0 of _TaskStatus2.

Note: If you enable parts rotation and issue a G0 move, the controller rotates the target position of the move. The motion does not follow a coordinated path.

Parts rotation can be activated in either G90 or G91 mode, but you cannot change the mode while parts rotation is active.

FOR EXAMPLE

This figure is described in the example program that follows.

Example

' Set the user units to primary units.
PRIMARY
' Enable incremental programming mode.
G91				
' Segment N1.
' Move the X axis 5 units in the positive direction.
G1 X5  F500
' Segment N3.
' Set the X, Y part rotation angle to 45°.
G84 X Y F45
' Move the X axis 5 units in the positive direction.
X5
' Segment N5.
' Set the X, Y part rotation angle to -45°.
G84 X Y F270
' Move the X axis 5 units in the positive direction.
X5
' Segment N7.
' Set the X, Y part rotation angle to 225°.
G84 X Y F630
' Move the X axis 5 units in the positive direction.
X5
' Segment N9.
' Disable parts rotation.
G84 X Y
' Move the X axis 5 units in the positive direction.
X5
' Segment N11.
' Reset the part rotation angle to -30°.							
G84 X Y F330
' Move the X axis 5 units in the positive direction.
X5
' Segment N13.
' Disable parts rotation.							
G84 X Y
' Move the X axis 5 units in the positive direction.
X5
