G82 Command (Restore Preset Position Registers)

Syntax: 
G82 <AxisMask>

Example:

 
G82 X Y    ; Remove G92 offsets from the X and Y axes.

Use the G82 command to restore the program position offsets to the values that were used before executing a G92 command. The G82 command will restore the program position offsets for the axes that you specify. If no axes are specified, the G82 command will restore the program position offsets for any axes previously set by a G92 command on the same task.

Note: If you are using Cutter Radius Compensation, use the G40 command to deactivate Cutter Radius Compensation before you issue the G82 command.

If no fixture offsets are active, a G82 command makes the program position equal to the machine position for the specified axes.
