G90 Command (Enable Absolute Programming Mode)

Syntax:

 
G90

Example:

 
G90     ; Specify the distances as absolute coordinates.

The controller interprets move target positions as absolute or incremental. Absolute mode means that move target positions are relative to a "0" location that is established by homing or a G92 Command. Absolute mode is set by default, but can be changed at any time during program execution. This command is modal and stays in effect until incremental programming mode is specified.

You can use the DefaultProgrammingMode parameter to set the default mode that is used by the task.

The absolute programming mode state is shown by Bit 1 of the TaskMode status value of the TASKSTATUS Status Function.

If an axis with a nonzero value for the RolloverCounts parameter is moved in G90 mode, its target position is adjusted to be within the RolloverCounts value. It travels the shortest distance to the target position.

The example program that follows executes as if the axes start at position (0, 0).

Example

' Enable absolute programming mode.
G90
' Set the feedrate for subsequent moves.
F100.
' Move the X and Y axes to absolute coordinate 10,10.
G1 X10.0 Y10.0
' Move the X and Y axes to absolute coordinate 15,25.
G1 X15.0 Y25.0
' Move the X and Y axes to absolute coordinate 15,10.
G1 X15.0 Y10.0
