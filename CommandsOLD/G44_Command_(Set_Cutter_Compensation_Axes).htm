G44 Command (Set Cutter Compensation Axes)

Syntax: 
G44 <axisMask>

Example:

 
G44 W V      ; Define the W axis as the X plane, the V
             ; axis as the Y plane.
 
G44 X Y Z

The G44 command specifies the axis pair that makes the X and Y plane that is used for cutter radius compensation and cutter offset compensation. The axis mask must contain two or three axis letters.

You must specify the axes in the correct order. The first two axes must be in the order specified by the circular plane specification. The first and second axes in the G44 command must also be the first and second axes specified in the G17, G18, or G19 command. The table that follows shows you the correct axes order for the G44 command.

Table:     Axes Order for the G44 Command

Circular Plane Mode G17 G18 G19

G44 order

G44 X Y

G44 Z X

G44 Y Z

You can specify a third axis, the Z axis in the plane, as the tool length axis. This third axis is used to compensate for the tool length supplied in the tool file and is activated by a G143 command. For more information on the tool file, refer to T Command.
