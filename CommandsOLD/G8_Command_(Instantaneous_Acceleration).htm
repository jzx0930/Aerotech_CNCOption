G8 Command (Instantaneous Acceleration)

Syntax: 
G8

Example:

 
G1 X5 F50        ; Velocity of F50
G8 G1 X5 F500    ; Instantaneously jump from F50 to F500

Note: Aerotech does not recommend using this command. It is supplied only for backward compatibility. To use instantaneous ramping, issue the RAMP RATE command with a value of 0.0.

Use the G8 command to instantaneously jump from an old to a new program velocity. It disables automatic acceleration and causes the motion to instantaneously accelerate or decelerate to the new programmed feedrate at the beginning of a coordinated move (G8 applies only to G1, G2, and G3 moves). Use this command with the TrajectoryIIRFilter parameter.

The figure (Velocity Profile with G8) displays a velocity profile with the G8 command. Without this command, acceleration is performed based on the settings of the acceleration mode. G8 applies only to coordinated motion, not G0 or asynchronous motion. A G8 must be on every line if instantaneous acceleration or deceleration is required on each line.

Note: G8 overrides G108/G109 for the current program line.

Example

' Enable incremental programming mode.
G91
' Set the time base to seconds.
G76
' Move the X axis 1 unit at 100 units/s.
G8 G1 X1 F100
' Move the X axis 1 unit at 200 units/s.
G8 G1 X1 F200
' Move the X axis 1 unit at 100 units/s.
G8 G1 X1 F100
Figure: Example of a Velocity Profile with G8 Example

Note: If motion is executing in the G8 mode and is placed into feedhold, the deceleration to zero is instantaneous. This also applies to MFO adjustments and the Abort button during a G8 mode move.

Note: The acceleration cannot occur in a period that is less than the value specified by the MotionUpdateRate parameter.
