G70 Command (Set English Units)

Syntax: 
G70

Example:

 
G70    ; Set the programming units to English units.

Use the G70 command to specify that distances and feedrates are in English units.

By default, the English units are mapped to the secondary units. This means that the SecondaryUnitsScaleFactor parameter is used for unit conversion. To map English units to primary units, use the PrimaryUnitsMapping parameter.

Each task maintains an independent G70 command or G71 command mode state.

Example

' Set the programming units to English units.
G70
' Move the X axis 10 English units in the positive direction.
G1 X10.
' Move the Y axis 5 English units in the negative direction.
G1 Y-5.
' Set the feedrate to 100 English units/time base.
F100.
