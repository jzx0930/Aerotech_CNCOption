G97 Command

Syntax: 
Gx97
Example: 
G97     ; Set the rotation speed for Spindle 0 to velocity units.
 
G297    ; Set the rotation speed for Spindle 1 to velocity units.
 
G397    ; Set the rotation speed for Spindle 2 to velocity units.
 
G497    ; Set the rotation speed for Spindle 3 to velocity units.

In Gx97 mode, the spindle speed (S command) is set to velocity units. The velocity units are determined by the CountsPerUnit parameter of the spindle axis and the DependentSpeedScaleFactor parameter. Gx97 mode is the default.

In either G97 or G96 mode, the spindle speed is limited by the MaxSpeedClamp axis parameter value and the S command always specifies the spindle speed. If you change modes with the spindle running, the value that is specified by the S command is reinterpreted by the new mode, and the spindle immediately accelerates or decelerates to the new speed.
