Parts Rotation Example

Before you run an AeroBasic example program, copy the example to your User Files directory. Copying the example makes sure that you have access to compile and run the program and prevents changes that you make from being overwritten if you install updated software.

View the example program in A3200 Motion Composer. Motion Composer adds color in the code which makes it easier to read. For best results, do one of the following.

  • Open a new file in Motion Composer. Copy and paste the code into the file.
  • OR
  • To examine the source code, open the example program from your User Files directory. You might have to copy the example program from the \A3200\Samples\AeroBasic folder first.

This example is one of many example programs. For a complete list of examples, refer to Example Programs.

To see a list of available hardware manuals, refer to Other Documentation. 

'				PartsRotation.pgm 
'
'
' This program makes 12 boats at 30 degree angle
' using parts rotation.  

'Absolute programming mode
G90
'Use metric units (which is the default)
G71 
'Use units per minute (default is seconds per unit)
G75           
'Turn rotation off for X and Y
G84 X Y       
ENABLE X Y 
HOME X Y 
'Set the feedrate for G0 commands
Ramp Rate X 1500   
Ramp Rate Y 1000    

'Go to position 70, 70 
G0 X70 Y70
'Define a software home here
G92 X0 Y0              
$global[0]=0              

'Repeat this code 12 times to make 12 boats
Repeat 12                  

	'Start rotation from 0
	G84 X Y F$global[0]       
	G91                  
	Ramp Rate X 750  
	G1 X50 F750 
	' Define a software home
	G92 X0 Y0                 
	
	'Absolute mode
	G90                       
	G1 X25
	G1 X20 Y-7.5 
	' a series of 5 waves
	G3 X17.5 Y-7.5 I-1.25 J0  
	G2 X15 Y-7.5 I-1.25 J0    
	G3 X12.5 Y-7.5 I-1.25 J0  
	G2 X10 Y-7.5 I-1.25 J0    
	G3 X7.5 Y-7.5 I-1.25 J0   
	' The front of the boat
	G1 X0 Y0                  'BOAT FRONT 
	' the next three make the sail
	G2 X12.5 Y22.5 I26.5 J0   
	G3 X12.5 Y0 I25 J-11.25   
	G3 X0 Y0 I-6.5 J-17.5     
	' Incremental programming mode
	G91                       
	' Goto the mast location
	G1 X12.5                 
	' Create the mast
	G1 Y25           
	' Create a fla
	G1 X5 Y-1.25              
	G1 X-5 Y-1.25 
	' Go back to Absolute mode
	G90                       
	' another sail
	G2 X25 Y0 I-14 J-22.5     
	G3 X12.5 Y0 I-6.25 J-17.5 
	G3 X12.5 Y22 I-25 J11.25  
	' return back to the software home
	G1 X0 Y0                  
	G91
	' move back to the center
	G1 X-50                  
	' set another software home
	G92 X0 Y0                 
	' rotate 30 degrees
	$global[0]=30            
ENDRPT
