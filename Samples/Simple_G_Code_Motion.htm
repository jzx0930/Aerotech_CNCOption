Simple G Code Motion Example

Before you run an AeroBasic example program, copy the example to your User Files directory. Copying the example makes sure that you have access to compile and run the program and prevents changes that you make from being overwritten if you install updated software.

View the example program in A3200 Motion Composer. Motion Composer adds color in the code which makes it easier to read. For best results, do one of the following.

  • Open a new file in Motion Composer. Copy and paste the code into the file.
  • OR
  • To examine the source code, open the example program from your User Files directory. You might have to copy the example program from the \A3200\Samples\AeroBasic folder first.

This example is one of many example programs. For a complete list of examples, refer to Example Programs.

To see a list of available hardware manuals, refer to Other Documentation. 

'				SimpleGcode.pgm 
'
'
' This is an introductory A3200 SMC part program example.
' It is a very basic example of how to generate G-Code motion.


' Create User DEFINEs.
#DEFINE On  1
#DEFINE Off 0
'
' Enable axes X, Y, Z, and U.
ENABLE X Y Z U
'
' Home the same axes.
HOME X Y Z U 
'
' Most CNC words (G70/G71/G90/G91/G1/F etc.) are Modal and
' stay in effect until turned off or changed.
'
' Change to English units, which are mapped to the secondary units.
' The default is Metric which is mapped to primary units (G71).
' Refer to the Help file for more information about G70 and G71.
' This is equivalent to using the SECONDARY keyword.
G70
'
' Change to Minutes mode.
' The default is SECONDS (G76).
G75
'
'  Set the Coordinated Motion Feedrate with an F command.
F 100
'
' The previous two lines can be added to the folloiwng line
' and written in one CNC block.
'       G70 G90 G1 X10 Y-10 Z.1 U-10.0 F100
'          or (spaces are not important)
'       G70G90G1X10Y-10Z10U-10.0F100
'
' Make an absolute (G90) G1 move.
G90 G1 X10 Y-10 Z.1 U-10.0
'
' Change to incremental mode.
G91
'
' Do an incremental coordinated move.
G1 Y-10 X5
'
' In a block, the order of CNC words DOES NOT change the meaning. But,
' many orders are illegal. Certain "types" of words must come before others.
' If you are not sure of where to put the words, separate 
' the words onto different lines. 
'          G70 G90 G1 Z10.5 U-5.5 F50    ' OK
'          G90 G70 G1 Z10.5 U-5.5 F50    ' OK
'          G70 G90 G1 U-5.5 Z10.5 F50    ' OK
'          F50 G70 G90 G1 Z10.5 U-5.5    ' This line is illegal. F cannot come before G1.
'
' Make an absolute G1 move by changing the feedrate.
G70 G90 G1 Z10.5 U-5.5 F50
'
' Make an absolute G0 (non-coordinated) move on X and U.
' X goes 50 ipm. U goes 20 ipm.
'              
XF 50
UF 20
G0 X-10 U10
