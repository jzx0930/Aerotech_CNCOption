Spindle Overview

Note: This feature applies only to dependent axes. For information about axis types, refer to Axis Type Overview.

A spindle is an axis that moves at a constant velocity. If an axis is designating as a spindle, a number of M-Codes and parameters provide enhanced control of its motion. You can also control an axis configured as a spindle using standard motion commands (for example G1) - the designation just allows the use of additional functions as described in the following sections. Many of these functions are RS-274-D compatible.

Each task can have up to four spindles. The numbered commands and parameters listed in the following sections correspond to spindle 0 (for example, Spindle0Axis). Spindles 1, 2, and 3 have corresponding commands and parameters with the correct numbers.

Setup

    Spindle0Axis

    Configure an axis as spindle 0

    AxisType

    Configure the spindle as a dependent axis

Speed

    DefaultSpindle0Speed

    Default rotation speed for spindle 0

    S Command

    Change the rotation speed of a spindle

    Spindle0MSOInput

    Control the MSO value using an analog input

    MSO Command

    Manual spindle rotation speed override

    M50 and M51

    Manual spindle rotation speed override lock

    G95

    Set feedrates to units per spindle revolution

    G96

    Set spindle rotation speed based on speed on surface of spindle

    G97

    Set spindle rotation speed to velocity units

Direction and Activation

    M3

    Spindle on clockwise

    M4

    Spindle on counterclockwise

    M103

    Spindle on clockwise (no wait)

    M104

    Spindle on counterclockwise (no wait)

    M5

    Spindle off

Behavior

    G100

    Set spindles as not affected by feedhold or the abort command

    G101

    Set spindles as affected by feedhold and the abort command

Status

    TaskStatus0 activation bits

    Status information
