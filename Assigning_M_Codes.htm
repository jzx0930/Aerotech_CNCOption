Assigning M-Codes

You can change the A3200 file \A3200\Samples\AeroBasic\CNC\Mcode.pgm to define your own M-Codes. You can define M-Codes in this file by using the #define preprocessor directive.

Note: Before you change the Mcode.pgm, copy the sample to your User Files directory to make sure that you have the correct access to compile and run the program. By copying the sample to your User File directory, you also prevent the changes that you make from being overwritten when you install updated software.

A default M-Code mapping is installed.

To define M-Codes, use these examples for Drive 1.

Examples

DVAR $MyVariable
' To read a binary input.
#define M1000 $DI[0].1
' The syntax that follows will execute $DI[0].1.
$MyVariable = M1000

' To read the state to which a binary output has been set.
#define M2000 $DO[0].1
' The syntax that follows will execute $DO[0].1.
$MyVariable = M2000

' To set a binary output.
#define M3000 $DO[0].1 = 1
' The syntax that follows will execute $DO[0].1 = 1.
M3000

' To clear a binary output.
#define M4000 $DO[0].1 = 0
' The syntax that follows will execute $DI[0].1 = 0.
M4000

' To set or clear a binary output.
#define M5000 $DO[0].1 =
' The syntax that follows will execute $DI[0].1 = , where value = 0.
M5000 0
' The syntax that follows will execute $DI[0].1 = , where value = 1.
M5000 1

Note: To put multiple M-Codes on the same program line or on the same line with G-Codes, you must follow with a blank line. To do this, include the back slash (\) character on the last line of text of the #define statement.
