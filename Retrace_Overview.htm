Retrace Overview

When you activate retrace, the controller executes motion and motion-synchronized commands in reverse order, through commands that previously executed. Coordinated motion commands (such as LINEAR, CW, and CCW) are executed in reverse, and motion retraces in reverse along the path that was made during forward execution of the program. Rapid motion commands are also executed in reverse, but because RAPID moves are not coordinated motion commands, the controller does not always retrace the same path as forward execution of the program. The controller also executes some synchronized non-motion commands during retrace.

The controller keeps a history of moves and synchronized commands that can be used for retrace. The number of moves and synchronized commands in the retrace history is determined by the value set for the MaxRetraceMoves Parameter.

RAMP MODE, RAMP RATE, RAMP RATE DEPENDENT, RAMP TIME, RAMP TYPE. SCURVE

VELOCITY ON/OFF

Reverts to previous setting.

Some AeroBasic commands such as asynchronous motion, string assignments, file operations, HOME, and other commands cannot be retraced through. If you execute one of these commands during normal program execution, the controller will clear the retrace history. If the controller reaches the end of the retrace history during retrace, the task will error.

To prevent a task from reaching the end of the retrace history and causing an error, use the TRACE END command. When retrace is active, the controller will not retrace past the TRACE END command. The controller will stay on the TRACE END command until retrace is disabled. The TRACE END command is ignored when retrace is not active.

The Retrace Mode status is indicated by the Retrace bit of the TaskStatus0 status item.

You can activate or deactivate retrace with one of the methods that follow.

Use the Retrace Mode Buttons of the CNC Operator Interface

You can activate or deactivate retrace in the Retrace Mode section of the CNC Operator Interface. The Retrace Mode section is available only when the task is running or paused.

To activate Retrace mode, click Change and then click On.

If you activate Retrace mode while the program is executing a command, the controller immediately decelerates motion. When the axes reach zero velocity, the controller enters Retrace mode, and the task is placed in feedhold. To continue executing the program in reverse, click Cycle Start.

If you activate Retrace mode while the program is paused, the controller stays paused until you click Cycle Start.

To deactivate Retrace mode, click Change and then click Off.

If you deactivate Retrace mode while the program is executing a command, the controller immediately decelerates motion. When the axes reach zero velocity, the controller exits Retrace mode, and the task is placed in feedhold. To continue executing the program in the forward direction, click Cycle Start.

Use the RETRACE Command in a program

You can activate or deactivate retrace in a program with the AeroBasic RETRACE command. The RETRACE command has the same behavior as when you use the Retrace mode buttons in the CNC Operator Interface, as described in the previous section. If you activate retrace with the RETRACE command, you can continue program execution with one of the actions that follow.

  • Click Cycle Start in the CNC Operator Interface.
  • Issue a Program Start in a program.
  • Issue a FEEDHOLD OFF in a program.
Set the MFO to a positive or negative value

You can activate or deactivate retrace if you set MFO to a negative value. You can do this if you give the MFO command a negative value or change MFO to a negative value from the CNC Operator Interface. The MFO method of retrace is different from the Retrace mode buttons and the RETRACE command because activation and deactivation of retrace occurs immediately and the controller does not put the task in feedhold.

Before you set the MFO Command to a negative value, you must set the MinimumMFO task parameter to a negative value that is equal to or less than what you want the MFO Command to be. For example, if you set the MFO Command to -100%, the MinimumMFO parameter must be -100% or less.

To activate retrace, make the <Value> argument of the MFO Command a negative value (for example, -100%). The controller immediately begins to reverse execute the command and continues to execute the program in the reverse direction.

To deactivate retrace, make the <Value> argument of the MFO Command a positive value (for example, 100%). The controller immediately begins to forward execute the command and continues to execute the program in the forward direction.

The controller automatically deactivates retrace when you issue a Program Stop, when a task error occurs, or when an ONGOSUB condition occurs.

Pause and Step Mode are disabled during retrace. To pause motion during retrace, issue the FEEDHOLD ON command and specify the task that is currently in retrace. To resume motion, issue a FEEDHOLD OFF command and specify the task that is currently in retrace.

After you exit retrace and start the program, the controller executes forward through the retrace history until it gets to the AeroBasic line where retrace was activated. While the controller is moving forward through the retrace history, it executes only commands that are moves or synchronized commands. It does not execute any other types of commands. When the controller gets to the line where retrace was activated, the AeroBasic program executes as usual.
