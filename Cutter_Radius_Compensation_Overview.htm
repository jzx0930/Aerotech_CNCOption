Cutter Radius Compensation Overview

Note: This feature causes the controller to activate lookahead. For more information, refer to Program Block Lookahead Overview.

The A3200 has two features that compensate for a cutting tool. You can use these features independently, or you can use both features at the same time.

  • Cutter Radius Compensation compensates for the radius of a cutting tool.
  • Cutter Offset Compensation compensates for the length and for the offsets of a cutting tool.

Use cutter radius compensation so that the controller maintains a constant offset that is perpendicular to the programmed path in a two-dimensional plane. You can use this feature to compensate for the diameter of a cutting tool or the width of a laser. The Cutter Radius Compensation Commands table shows the cutter radius compensation commands that you can use.

Note: This feature applies only to dominant axes. For information about axis types, refer to Axis Type Overview.

Table:     Cutter Radius Compensation Commands

Command

Description

G40

Deactivates cutter radius compensation.

G41

Activates cutter radius compensation left.

G42

Activates cutter radius compensation right.

G43

Specifies the radius of the cutting tool.

G44

Specifies the axes that you want to use for cutter radius compensation.

Important Notes

  • Cutter radius compensation maintains an offset from the programmed path during coordinated (G1, G2, G3, and BEZIER) motion. During G0 motion, the controller does not try to maintain the offset because G0 does not follow a coordinated path.
  • The controller does not do cutter radius compensation on moves that you issue as an immediate command.
  • When you home an axis, the controller deactivates cutter radius compensation.
  • If you use the corner rounding and cutter compensation features at the same time, then you must use the same two axes for both features.
  • You can use cutter radius compensation during parts rotation (G84), mirroring (G83), or with Normalcy Motion commands.

  • Note: When mirror mode (G83) is active, cutter radius compensation left becomes cutter radius compensation right and cutter radius compensation right becomes cutter radius compensation left.
