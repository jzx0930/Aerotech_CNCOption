ROUNDING AXES Command

Specifies the axis pair on which rounding is done.

Syntax:

 
ROUNDING AXES <RoundingAxis1> <RoundingAxis2>

Example:

 
ROUNDING AXES W V

Table:     ROUNDING AXES Command Arguments

Argument

Type

Description

<RoundingAxis1>

Axis

Specifies the first axis of the axis pair.

<RoundingAxis2>

Axis

Specifies the second axis of the axis pair.

Use the ROUNDING AXES command to specify the axis pair that makes the X and Y plane that is used for corner rounding.

Note: If you use the corner rounding and cutter compensation features at the same time, then you must use the same two axes for both features.
