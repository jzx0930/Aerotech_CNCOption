ROUNDING ON/OFF Command

Turns on or turns off corner rounding.

Syntax:

 
ROUNDING ON
 
ROUNDING OFF

Example:

 
ROUNDING ON
ROUNDING OFF

Use the ROUNDING ON Command to turn on corner rounding. When corner rounding is on, an arc is inserted between two consecutive non-tangent LINEAR moves. Corner rounding calculates the radius of the arc by using the tolerance you specify in the ROUNDING TOLERANCE Command.

Use the ROUNDING OFF command to turn off corner rounding.

Corner rounding occurs only between the consecutive LINEAR moves that are between the ROUNDING ON command and the ROUNDING OFF command in your program.
