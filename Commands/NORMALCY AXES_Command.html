NORMALCY AXES Command

Specifies the axes to which normalcy is applied.

Syntax:

 
NORMALCY <NormalcyAxis> AXES <NormalcyX> <NormalcyY>

Example:

 
NORMALCY X AXES Z Y

Table:     NORMALCY AXES Command Arguments

Argument

Type

Description

<NormalcyAxis>

Axis

Specifies the normalcy axis. This axis must be a dependent type axis.

<NormalcyX>

Axis

Specifies the X axis of the axis pair. This axis must be a dominant type axis

<NormalcyY>

Axis

Specifies the Y axis of the axis pair. This axis must be a dominant type axis

Use the NORMALCY AXES command to specify the axes used in normalcy motion.

Table:     NORMALCY AXES Command Arguments

Argument

Description

<NormalcyAxis>

Axis to use as the normalcy axis. This axis must be a dependent type axis. (Refer to Axis Type Overview for more information.)

<PlaneXaxis>

Axis to use as the X axis of the normalcy plane. This axis must be a dominant type axis.

<PlaneYaxis>

Axis to use as the Y axis of the normalcy plane. This axis must be a dominant type axis.

When enabled, the normalcy axis maintains a normal (perpendicular) orientation to the coordinated motion path. The following figure shows the relationship between the orientation of the normalcy axis and the path of the axes of the normalcy plane.
